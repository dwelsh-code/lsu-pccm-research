# TASK_BRIEF

Updated: 2026-11-08

## Primary objective

Create an externally hosted website for clinical and translational science research that gives LSU Health faculty and fellows one practical place to find research resources, LSU-specific procedures and documents, research tools, expert support, and section research conference schedules.

## Confirmed direction

Externally hosted site, LSU Health graphic style, practical local research support, section conference calendar, and the existing database registry as the initial data-resource module. CTS Essentials is the design/function reference.

## Current deliverable

A built static website, single-file preview, curated source snapshot, readable planning/reference materials, and the latest Word database registry. See notes/2026-11-08-first-website-release.md for verified build status and remaining publication blockers.

## Proposed first release

Task-based navigation; searchable resources; IRB and REDCap guides linked to verified LSU sources; database filtering; conference agenda and section filters; working help routes; accessible responsive presentation; and clear resource review metadata. The proposed first-release details are recommendations, not deployed functionality.

## Outstanding

Canonical installation, exact resource and conference sources, final public title, domain/provider, content editors, implementation checkout and remote, development, validation, and deployment.

## Rapid launch priority

User direction, November 8 2026: prioritize getting a usable website up quickly. Avoid an extended development or planning process. Continued development and expansion can follow the initial release.

### Initial release

- A simple responsive homepage using LSU Health visual style, hosted outside LSU’s website.
- Direct navigation to research databases, IRB resources and documents, REDCap, research help, and conferences.
- The existing 40-resource database inventory available to browse; basic search or topic filtering only if quick to implement.
- A small set of verified official LSU IRB and REDCap links, with concise descriptions. Do not wait for a complete institutional resource inventory.
- A simple conference schedule or a working link to an authoritative existing schedule. Add confirmed events incrementally; do not delay the entire site for missing section schedules or invent events.
- A working contact/correction route when its destination is verified.

### Release checks

Confirm that the main links and database document open, navigation works on desktop and mobile, the content is readable and keyboard accessible, and the site identifies its purpose and operator accurately. Use focused checks appropriate to this small release; do not expand the task into a platform build.

### Later development

Expanded content, richer filters, calendar feeds, custom editor tools, user accounts, saved resources, AI guidance, and custom integrations can follow. None is a prerequisite for the first usable release. Use existing destinations and simple links wherever practical.

### Next action

Move directly into a small working website implementation using the existing registry and a few verified LSU links. Validate and deploy the initial version, then improve it iteratively. Complete only the minimum project setup required to build and preserve the work reliably. Do not turn a full content audit, elaborate specification, or comprehensive feature set into a launch gate.
