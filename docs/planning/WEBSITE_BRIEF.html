CTS Research Hub Website Brief

Rapid launch is the priority

Build and launch a small usable site now, then improve it over time. Start with the existing database registry, a few verified LSU IRB and REDCap links, simple topic navigation, and a basic conference schedule or authoritative schedule link. Use the LSU Health visual style and external hosting. A complete resource inventory is not a launch prerequisite.

Defer accounts, AI guidance, custom integrations, advanced filtering, and custom administration. Check core links, mobile/desktop navigation, readability, and keyboard access before release. Move directly into the initial implementation after minimum required setup.

November 8 2026

Create an externally hosted website for clinical and translational science research that gives LSU Health faculty and fellows one practical place to find research resources, LSU-specific procedures and documents, research tools, expert support, and section research conference schedules.

Proposed home page

Lead with “What do you need to do?” and a visible resource search. Provide direct task links for IRB, REDCap, databases, documents, research help, and conferences. Offer research-stage browsing as a secondary path. Show a small upcoming-conferences agenda with a route to the full schedule. Experienced users should be able to reach a known resource immediately.

Resource records

Each record should include a title, concise summary, category, research stage, source organization, official URL, access requirements, resource type, responsible editor, last verified date, and related help. Documents should identify their current official source and version or date when available. Prefer links to current institutional forms over uncontrolled copies.

Conference records

Each event should contain the section, conference title, actual date and time, America/Chicago timezone, location or authorized meeting link, organizer, recurrence details, and cancellation or exception information. Conference schedules have not yet been verified. Private meeting links should follow the selected audience model rather than appearing automatically on a public page.

Visual design

Use the LSU Health palette and graphic standards, with purple headings and navigation, restrained gold emphasis, generous whitespace, and accessible responsive layouts. The graphics manual specifies Meta OT for organizational identifiers; do not assume that licensed web-font files are available. Confirm available font assets before final typography. Reuse authorized logo assets without redrawing or altering them if logo use is part of the approved design.

External hosting is the user’s requirement. The official LSU web standards describe institutional CMS expectations separately from visual standards. Mirroring the guide does not establish institutional hosting, endorsement, or an exception to institutional publishing rules. The site’s operator and relationship to LSU should be described accurately.

First implementation scope

  1. Searchable resource registry and task navigation seeded with the existing 40 databases.
  2. Verified LSU IRB and REDCap links, instructions, and documents.
  3. Real section conference schedule with topic/section filtering and agenda view.
  4. Resource maintenance fields and a working correction/contact route.
  5. Responsive and keyboard-accessible design using LSU Health visual standards.

Later options

Consider saved resources, calendar subscriptions, integrations, and approved-source AI assistance after the core directory and maintenance process work reliably. These are proposed future options, not existing features or scheduled automations.

Next work

Build a small first release immediately using the existing registry and a few verified LSU resource links. Gather additional content and expand the conference schedule during subsequent iterations. The first prototype should clearly label unverified content instead of fabricating instructions or conference events.
