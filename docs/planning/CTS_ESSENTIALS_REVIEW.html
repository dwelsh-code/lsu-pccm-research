CTS Essentials Design and Function Review

Reviewed November 8 2026 from saved project materials

The relevant reference is LA CaTS CTS Essentials, associated with the la-cats-pd planning project and la-cats-pd-demo website. The design brief, sitemap notes, saved React page, and styles were reviewed. Site metadata reported version 13; live browser access was declined, so no claim is made that the saved source exactly matches the live publication or that browser interactions were tested.

What should differ

The new hub is a resource and operations destination for LSU Health faculty and fellows. It should preserve direct access to databases, forms, REDCap, and conference schedules. Requiring a lesson cascade for every task would add unnecessary clicks, and a multi-institution selector would add complexity to an LSU-focused site. Conference scheduling is a new requirement; it is not a demonstrated feature of the inspected CTS Essentials source.

Implementation cautions from the reference

The saved prototype includes illustrative videos and checklist buttons, placeholder local help, a keyword-based adviser, and a consultation confirmation that does not send a request. Carry over the interaction ideas, but implement the underlying destinations before presenting them as operational. Use LSU Health purple and gold rather than the LA CaTS blue/gold styling, and do not copy the reference project’s branded content, institutional roster, or service-routing assumptions.
